# Créer un ensemble de données

Parfois, vous devrez peut-être créer un ensemble de données si vous travaillez avec vos propres données. Créer un ensemble de données avec 🤗 Datasets confère tous les avantages de la bibliothèque à votre ensemble de données : chargement et traitement rapides, interopérabilité avec l'ensemble de l'écosystème 🤗 et partage facile sur le Hub.

Dans ce didacticiel, vous apprendrez comment utiliser les méthodes low-code de 🤗 Datasets pour créer tous types d'ensembles de données :
In this tutorial, you'll learn how to use 🤗 Datasets low-code methods for creating all types of datasets:

* Constructeurs basés sur des dossiers pour créer rapidement un ensemble de données d'images ou d'audio
* Méthodes `from_` pour créer des ensembles de données à partir de fichiers locaux

## Constructeurs basés sur des fichiers

🤗 Datasets prend en charge de nombreux formats courants tels que `csv`, `json/jsonl`, `parquet`, `txt`.

Par exemple, il peut lire un ensemble de données composé d'un ou plusieurs fichiers CSV (dans ce cas, passez vos fichiers CSV sous forme de liste) :

```py
>>> from datasets import load_dataset
>>> dataset = load_dataset("csv", data_files="my_file.csv")
```

Pour obtenir la liste des formats pris en charge et des exemples de code, suivez ce guide [here](https://huggingface.co/docs/datasets/loading#local-and-remote-files).

## Constructeurs basés sur des dossiers

Il existe deux constructeurs basés sur des dossiers, [`ImageFolder`] and [`AudioFolder`]. Ce sont des méthodes low-code pour créer rapidement un ensemble de données d'images ou de discours et d'audio avec plusieurs milliers d'exemples. Ils déduisent les divisions des ensembles de données de la structure du dépôt et les noms des étiquettes des noms des répertoires.

* [`ImageFolder`] utilise la fonctionnalité [`~datasets.Image`] pour décoder un fichier image. De nombreux formats d'extension d'image sont pris en charge, tels que jpg et png, mais d'autres formats sont également pris en charge. Vous pouvez consulter la liste complète [list](https://github.com/huggingface/datasets/blob/b5672a956d5de864e6f5550e493527d962d6ae55/src/datasets/packaged_modules/imagefolder/imagefolder.py#L39) of supported image extensions.
* [`AudioFolder`] utilise la fonctionnalité [`~datasets.Audio`] pour décoder un fichier audio. Les extensions audio telles que wav et mp3 sont prises en charge, et vous pouvez consulter la liste complète [list](https://github.com/huggingface/datasets/blob/b5672a956d5de864e6f5550e493527d962d6ae55/src/datasets/packaged_modules/audiofolder/audiofolder.py#L39) of supported audio extensions.

Les divisions des ensembles de données sont générées à partir de la structure du dépôt et les noms des étiquettes sont automatiquement déduits du nom du répertoire.

Par exemple, si votre ensemble de données d'images (c'est la même chose pour un ensemble de données audio) est stocké comme ceci :

```
pokemon/train/grass/bulbasaur.png
pokemon/train/fire/charmander.png
pokemon/train/water/squirtle.png

pokemon/test/grass/ivysaur.png
pokemon/test/fire/charmeleon.png
pokemon/test/water/wartortle.png
```

Alors, voici comment le constructeur basé sur des dossiers génère un exemple :

<div class="flex justify-center">
    <img src="https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/datasets/folder-based-builder.png"/>
</div>

Créez l'ensemble de données d'images en spécifiant `imagefolder` dans [`load_dataset`]:

```py
>>> from datasets import load_dataset

>>> dataset = load_dataset("imagefolder", data_dir="/path/to/pokemon")
```

Un ensemble de données audio est créé de la même manière, sauf que vous spécifiez `audiofolder` dans [`load_dataset`] à la place :

```py
>>> from datasets import load_dataset

>>> dataset = load_dataset("audiofolder", data_dir="/path/to/folder")
```

Toute information supplémentaire sur votre ensemble de données, telle que des légendes de texte ou des transcriptions, peut être incluse avec un fichier `metadata.csv` dans le dossier contenant votre ensemble de données. Le fichier de métadonnées doit comporter une ligne d'en-tête `file_name` avec les noms des colonnes que vous souhaitez utiliser et chaque ligne en dessous doit correspondre à un fichier de votre ensemble de données :

```
file_name, text
bulbasaur.png, There is a plant seed on its back right from the day this Pokémon is born.
charmander.png, It has a preference for hot things.
squirtle.png, When it retracts its long neck into its shell, it squirts out water with vigorous force.
```

Pour en savoir plus sur chacun de ces constructeurs basés sur des dossiers, consultez la documentation <a href="https://huggingface.co/docs/datasets/image_dataset#imagefolder"><span class="underline decoration-yellow-400 decoration-2 font-semibold">ImageFolder</span></a> or <a href="https://huggingface.co/docs/datasets/audio_dataset#audiofolder"><span class="underline decoration-pink-400 decoration-2 font-semibold">AudioFolder</span></a>.

## À partir de dictionnaires Python

Vous pouvez également créer un ensemble de données à partir de données dans des dictionnaires Python. Il existe deux façons de créer un ensemble de données à l'aide des méthodes `from_` :

    * La méthode [`~Dataset.from_generator`] est la façon la plus efficace en termes de mémoire de créer un ensemble de données à partir d'un [generator](https://wiki.python.org/moin/Generators) en raison du comportement itératif des générateurs. Ceci est particulièrement utile lorsque vous travaillez avec un ensemble de données très volumineux qui peut ne pas tenir dans la mémoire, car l'ensemble de données est généré progressivement sur le disque, puis mappé en mémoire.

    ```py
    >>> from datasets import Dataset
    >>> def gen():
    ...     yield {"pokemon": "bulbasaur", "type": "grass"}
    ...     yield {"pokemon": "squirtle", "type": "water"}
    >>> ds = Dataset.from_generator(gen)
    >>> ds[0]
    {"pokemon": "bulbasaur", "type": "grass"}
    ```

    Un [`IterableDataset`] basé sur un générateur doit être itéré avec une boucle `for` par exemple :

    ```py
    >>> from datasets import IterableDataset
    >>> ds = IterableDataset.from_generator(gen)
    >>> for example in ds:
    ...     print(example)
    {"pokemon": "bulbasaur", "type": "grass"}
    {"pokemon": "squirtle", "type": "water"}
    ```

    * La méthode [`~Dataset.from_dict`] est un moyen simple de créer un ensemble de données à partir d'un dictionnaire :

    ```py
    >>> from datasets import Dataset
    >>> ds = Dataset.from_dict({"pokemon": ["bulbasaur", "squirtle"], "type": ["grass", "water"]})
    >>> ds[0]
    {"pokemon": "bulbasaur", "type": "grass"}
    ```

    Pour créer un ensemble de données d'images ou d'audio, enchaînez la méthode [`~Dataset.cast_column`] avec [`~Dataset.from_dict`] et spécifiez la colonne et le type de fonctionnalité. Par exemple, pour créer un ensemble de données audio :

    ```py
    >>> audio_dataset = Dataset.from_dict({"audio": ["path/to/audio_1", ..., "path/to/audio_n"]}).cast_column("audio", Audio())
    ```
